# RJ Creative Hub — React + SCSS

A responsive single-page website inspired by the supplied RJ Creative Hub artwork.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build for production

```bash
npm run build
npm run preview
```

## Main files

- `src/App.jsx` — complete one-page layout/content
- `src/styles/main.scss` — responsive SCSS styling
- `public/assets/rj-creative-hub-banner.png` — supplied artwork used in the hero
